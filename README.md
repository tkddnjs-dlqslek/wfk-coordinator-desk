# WFK 코디 데스크: 해외봉사단 코디네이터 업무 도우미

2026 KOICA 공공데이터 활용 챌린지 출품작. 본선 진출(6팀). 개인 참가.

## 무엇인가

KOICA 해외봉사단(WFK) 현지 코디네이터가 매달 반복하는 일을 Claude API로 줄여 주는 웹 앱.
공개 데이터(KOICA 사업 통계, 단원 배치 현황)와 코디네이터가 직접 입력하는 운영 기록(단원 명부, 역량 평가, 만족도)을 같이 써서, 내부 데이터 없이도 현장에서 쓸 수 있게 설계함.

| 직무 | 기능 |
|---|---|
| 사업 성과 | 지역별 단원 수요와 미배치 시급도, 만족도와 현장 의견 기록 |
| 현장 프로젝트 | 현장 사업 발굴과 벤치마크(수혜자 수, 예산 효율 순위), 홍보 카드 생성 |
| 역량 개발 | 교육자료 생성과 갱신, 퀴즈 배포와 자동 채점, 역량 대장과 기수 비교, 교육용 PPT 제자리 번역, 회의록 통합 요약 |

## 기술

- Next.js, Supabase(Postgres), Vercel 배포, Claude API(생성과 요약), Google 로그인과 역할별 화면
- 생성물은 공통 스타일 가이드로 말투와 형식을 통일. PPT 번역은 원본 디자인을 유지한 채 글상자 안에서 번역문 길이에 맞춰 글자 크기를 조정
- 테스트 82개, 역할 위조 쿠키 차단 검증
