## 0. 오프닝 (약 20초)

[S1: 표지 — WFK 어시스턴트]

안녕하세요. 팀 **코디파일럿**의 김상원입니다. KOICA 해외봉사단 현장의 운영 부담을 데이터로 덜어주는 **WFK(World Friends Korea) 어시스턴트**를 만들었습니다.
발표는 "왜 이 서비스가 필요한가"에서 시작해, 실제 현업 코디네이터 분들의 인터뷰를 통해 서비스가 어떻게 바뀌었는지, 그리고 서비스의 기능과 작동 방식이 어떠한지, 마지막으로 기대 성과와 장단점 순서로 말씀드리겠습니다.

[S2: 목차 — 넘기며 한 문장] 순서는 화면과 같습니다.

## 1. 목적과 실제 인터뷰 — 왜 필요한가 (약 2분)

[S3: 문제 — 인원수 · 직무의 폭 · 도구 부재]

KOICA 해외봉사단은 파견국마다 **현지 코디네이터**들이 단원들의 현지적응교육, 복무, 안전, 귀국까지 운영 전반을 책임집니다. 코디네이터 **1인당 담당 단원이 약 15명**으로 인원 부담이 크고, 여기에 안전·교육·역량·홍보·행정을 아우르는 **직무의 폭**까지 넓습니다. 그런데 정작 이 반복 업무를 효율적으로 처리하고 표준화할 **자동화 도구는 부족한 실정**입니다.
실제 현장의 목소리도 이를 뒷받침합니다. 새 협조문·문서를 쓸 때 시간이 많이 들고, 참고할 레퍼런스는 타 사무소 공람 정도뿐이며, 업무가 매뉴얼화되어 있지 않다고 합니다. 즉 **인원수·직무 다양성·도구 부재가 맞물린 구조적 문제**이고, 비슷한 일을 각자 반복하는 구조입니다.

[S4: 그래서 필요한 것 — 하나의 웹]

그래서 필요한 건 분명했습니다.
첫째, 이 반복·문서 업무를 **빠르게 '돌릴 수 있는' 하나의 웹 도구.** 예를 들어 교육자료를 몇 번의 클릭으로 만들고, 현지어로 번역하고, PPT로 바꾸는 것이죠.
둘째, 코디네이터와 단원, 나아가 **코디네이터들 사이의 상호 피드백**이 한곳에서 오가는 구조.
**모든 기능이 하나의 웹에서 돌아가야, 각 코디네이터의 업무 효율이 실제로 올라갑니다.**

[S5: 인터뷰 — 볼리비아 사무소 서면 8문항 → 실수요]

그래서 저는 상상하지 않고 **직접 물었습니다.** KOICA 담당 과장님의 주선으로 **볼리비아 사무소 현직 코디네이터의 서면 인터뷰**를 8개 문항으로 받았고, 담당 과장님과도 계속 소통했습니다.
화면의 답변들이 현장 표현 그대로입니다. (슬라이드의 매핑을 짚어가며)
1. **"자가진단은 신뢰하기 어렵다 — 코워커·파견기관 동료의 객관적 판단이 더 정확하다."**
2. **"정기적인 애로사항 수집은 사무소 업무 과중"** + **"정신건강을 스스로 점검해보는 도구가 있으면 유용하겠다."**
3. 홍보는 **편집·번역·자막에 한국인 직원의 품**이 많이 들고, **"단원 소개·사무소 소개는 균일 양식이 있다면"** 하는 제안.
4. **현지직원 서류·자료를 번역해 붙여야 하는 경우가 많다.**
5. **"보이스 메모를 회의록으로 변환하는 도구도 유용할 듯."**
이 답변 하나하나가 화면처럼 **기능 하나하나로 이어졌습니다.** 즉 목적은 단순합니다. **코디네이터의 반복 업무는 자동화하고, 단원의 적응·역량·안전은 데이터로 받쳐주는 것.**

## 2. 서비스 설명 — 어쩌다 이런 서비스가 나왔나 (약 1분 45초)

[S6: 두 개의 축 — 코디네이터 / 단원]

문제의 주체가 **둘**이었습니다. 부담을 지는 **코디네이터**와, 지원을 받아야 하는 **단원**입니다.
그래서 하나의 앱 안에 **역할별로 다른 두 화면**을 두었습니다. **구글 로그인**으로 들어오면, 명부에 등록된 사람은 코디네이터 화면을, 단원은 자기 것만 보이는 화면을 받습니다. 권한이 분리돼 단원은 남의 정보를 못 봅니다.

[S7: 어떻게 만들었나 — JD로 뼈대, 인터뷰로 수정]

만든 순서가 중요합니다.
저는 먼저 **KOICA 코디네이터의 직무기술서(JD)** 를 바탕으로 **기본 구조**를 잡았습니다. 코디네이터가 실제로 맡는 직무 — 안전관리, 교육, 역량평가, 홍보, 행정 — 를 그대로 기능으로 옮긴 겁니다.
그다음, **볼리비아 사무소 인터뷰와 KOICA 담당자 피드백**으로 그 구조를 **수정·보강**했습니다. 코워커 외부평가, 웰빙 체크인, 홍보 소개템플릿, PPT 번역, 회의록이 이때 추가되거나 바뀌었습니다.
반대로, 처음 넣으려던 '수동 상담 리퍼럴'은 **실제 상담 자원이 확정되지 않아** 빼버렸습니다. 있는 척하지 않았습니다.
즉 **JD로 뼈대를 세우고, 현장 목소리로 살을 붙였습니다.**

[S8: 이중 데이터 · RAG 파이프라인 — 도식 짚어가며, 약 45초]

작동 원리를 조금만 자세히 말씀드리겠습니다. (도식을 왼쪽부터 짚으며)
먼저 **데이터**입니다. KOICA 공공데이터 — **국별 협력사업 실적과 사업개요서, 국제개발협력 표준용어집** — 에 **World Bank 개발지표, 안전·보건 지표**까지, **약 5,000건**을 확보했습니다. 여기에 코디네이터가 현장에서 쌓는 **운영 데이터** — 명부, 역량대장, 피드백, 회의록 — 가 더해집니다.
이걸 그냥 쌓아두는 게 아니라, **정규화하고 다국어 임베딩으로 벡터화해서 pgvector 벡터 DB에 저장**합니다. 사용자가 국가와 분야를 고르면, 시스템이 **의미 검색으로 그 질문과 관련된 근거만 추려서** AI에게 건네줍니다. 이게 RAG입니다.
그리고 마지막 단계가 저희의 핵심 원칙입니다 — AI는 **건네받은 근거 안에 있는 것만** 쓰고, **모든 사실 문장에 [출처]를 강제**합니다. 근거가 없으면 지어내는 게 아니라 '자료 없음'으로 정직하게 표기합니다. 생성 결과의 **[출처]를 누르면 원문으로 연결**되니, 제출 전에 누구나 검증할 수 있습니다.
ChatGPT 같은 일반 LLM과의 차이가 여기 있습니다. **그럴듯한 답이 아니라, 검증된 공공데이터로 증명되는 답**입니다.

## 3. 기능 구체적 설명 (약 2분 30초) — 슬라이드마다 실제 화면

[브릿지 — S9 넘어가기 직전, 약 15초]

지금부터 기능을 보여드릴 텐데, 보시면 **기능이 꽤 많습니다.** 이건 저희가 욕심을 부려서가 아니라, 앞서 보신 것처럼 **코디네이터의 직무 자체가 교육·역량·번역·회의·홍보까지 넓기 때문**입니다. 저희는 직무기술서의 **직무 하나에 기능 하나를 대응**시켰습니다. 그래서 기능이 많은 게 아니라, **코디네이터의 하루가 이만큼 넓은 겁니다.** 그 순서 그대로 보여드리겠습니다.

[S9: 기능① 교육자료 생성]

- **현지적응훈련 교육자료 생성**: 국가·분야를 고르면 공공데이터 근거로 만듭니다. 인터뷰에서도 "신규 파견 코디네이터는 단원보다 현지를 잘 모르는 경우도 있다"고 했는데, 그 공백을 데이터가 메웁니다. 방금 보신 RAG로 생성하니 **모든 수치에 [출처]가 붙어 클릭하면 원문으로 연결**되고, 사망률 같은 지표는 **"한국 대비 어느 위치인지"** 로 교육적으로 설명하며, 그대로 **PPT로 변환**됩니다. 파견국의 안전·치안·보건 유의사항도 이 자료가 함께 짚어줍니다.

[S10: 기능② 역량대장 · 기수 비교]

- **역량대장 + 기수 비교**: 단원 명부를 엑셀로 올리면, 역량이 기수별로 어떻게 발전하는지 비교됩니다. 명부와 역량대장이 **같은 사람으로 연동**되고, 역량대장은 **주관적 수동입력 없이 퀴즈 결과와 코워커 외부평가(객관 데이터)로만** 채워집니다. 코디네이터가 퀴즈를 만들어 **국가 단위로 배포**하면 응시 결과·오답이 자동으로 쌓이고, 단원 평가를 **파견기관 코워커에게 전송하면 코워커가 구글 로그인해 자기 수신함에서 5개 영역을 직접 평가**합니다 — 인터뷰의 "자가진단은 신뢰 어렵고 코워커 평가가 더 정확하다"를 그대로 구현한 겁니다.

[S11: 기능③ 회의록]

- **회의록**: 녹음을 전사해 올리면 AI가 회의록으로 정리하고, **공공데이터와 연관지어 벡터 RAG에 저장**합니다. 다음 회의가 들어오면 **이전 회의 대비 무엇이 해결되고, 무엇이 진행 중이고, 무엇이 새로 생겼는지** 자동으로 짚어줍니다. 여러 회의를 **통합 요약**해 안건별 흐름을 타임라인으로 만들고, 그 요약을 **다른 코디네이터에게 전송**할 수 있습니다 — 코디네이터 간 공통 도구 부재를 푸는 기능입니다.

[S12: 기능④ PPT 번역]

- **PPT 번역**: 디자인은 그대로 두고, **공공데이터로 적재한 KOICA 국제개발협력 표준 용어집**과 **언어별 폰트**를 적용해 레이아웃이 깨지지 않게 번역합니다. 용어집을 DB에 넣어두고 번역 시 끌어쓰기 때문에, 일반 기계번역과 달리 **같은 개발협력 용어를 항상 같게** 옮깁니다.

[S13: 기능⑤ 홍보 카드뉴스 · 소개템플릿]

- **홍보 카드뉴스 / 소개템플릿**: 홍보는 **실제 KOICA 콘텐츠 형식을 그대로 따르는 카드뉴스 3종** — 사업 성과형, 팩트·OX 퀴즈형, '이달의 단원' 월터뷰형 — 으로 만들며, 공공데이터·활동데이터를 근거로 모든 수치에 [출처]가 붙습니다. 또 인터뷰의 "균일 양식이 있다면" 제안을 반영해 **단원 소개·사무소 소개를 편집 가능한 균일 양식**으로 냅니다 — 사무소 소개는 KOICA 해외사무소의 **실제 구성(About Us·소장 인사말·중점협력분야·사무소 활동·연락처)** 을 그대로 따릅니다.

[S14: 기능⑥ 단원 화면]

**단원 화면**은 자기에게 필요한 것만 봅니다.
- 배포된 **퀴즈**와 점수, 자기 파견국 **교육자료 열람** — 본인 **직종에 맞는 분야가 자동 선택**됩니다.
- **ODA 활동 만족도**: 보람(자아실현)과 업무 애로를 묻는 5문항으로, 업무 부담이 크면 코디네이터에게 신호가 갑니다. 인터뷰의 "정기적 수집은 사무소 업무 과중"을 뒤집어, **단원이 직접 입력하고 시스템이 모아주는** 방식입니다.
- **WHO-5 웰빙 체크인**: 국제 검증 5문항 웰빙 지수로 **격주** 자기 점검. 만족도와 달리 **개인 심리 상태**를 보며, 진단이 아닌 스크리닝입니다. 인터뷰의 "정신건강을 스스로 점검해보는 도구" 요청에 대한 답입니다.

## 5. 기대 성과 · 장단점 (약 1분 30초)

[S16: 기대 성과 (+적용 가능성 구두)]

이 서비스는 **지금 바로 KOICA WFK 봉사단 사업에 붙일 수 있습니다.** 이미 KOICA 공공데이터를 근거로 쓰고, 구글 로그인과 명부 업로드만으로 파견국·기수 단위로 운영됩니다. 파견국을 늘리거나 다른 ODA 기관으로 확장하는 것도 데이터만 얹으면 됩니다.
기대 성과는 세 가지입니다.
- **코디네이터 업무시간 절감** — 교육자료·번역·회의록·홍보의 반복 작업 자동화,
- **단원 초기 적응·안전사고 예방** — 교육자료가 파견국 안전·보건 지표를 한국 대비로 짚어주는 데이터 기반 사전 교육,
- **코디네이터 간 표준화·상호 피드백** — 회의록 요약 전송·공유로 운영 품질을 고르게.

[S17: 장점 — 한계는 슬라이드에 없음, 구두로만]

**장점**: ① 모든 결과가 공공데이터에 근거하고 출처가 투명, ② 코디네이터·단원 역할이 분리된 실제 운영 구조, ③ 상상이 아니라 **JD와 현장 인터뷰로 검증된 기능**.
**한계도 솔직히 말씀드리면**: 회의록의 전사 품질은 외부 도구에 의존하고, 번역은 최종 검수가 필요하며, 웰빙은 진단이 아닌 스크리닝이고, 공공데이터 커버리지가 국가마다 차이가 납니다. 이 한계를 **숨기지 않고 설계에 반영**했습니다.

[S18: 클로징]

정리하면, WFK 어시스턴트는 **"코디네이터의 손을 덜고, 단원을 데이터로 지킨다"** 한 문장으로 요약됩니다. 감사합니다.

### 발표자 메모
- **시간 규칙(이자영 과장 확인)**: 발표 10분 안에 시연 영상 포함 + 질의 10분. 위 구성 = 발표 ~7분 50초 + 영상 ~2분 = 여유 ~10초. 넘치면 3부 브릿지를 두 문장으로 축약.
- 문제 프레이밍 = **인원수(15:1) + 직무의 폭 + 자동화 도구 부재** 삼중 구조(기획요약서와 통일).
- 인터뷰는 **볼리비아 사무소 서면 답변**(이자영 과장 주선) — "직접 만났다"고 말하지 말 것. 실수요 인용은 S5 한 장에서 소화(별도 실수요 슬라이드 삭제됨).
- S8은 **도식을 왼쪽부터 손으로 짚어가며** — 데이터(5,000건) → 임베딩 → pgvector → 의미검색(RAG) → 출처 강제 → 클릭 검증 순.
- 개발 흐름은 반드시 **JD → 인터뷰 수정** 순서로(신뢰 포인트). 상담 리퍼럴 뺀 이야기 = '있는 척 안 했다' 포인트.
- **출처 색 언급 금지** — "[출처]를 누르면 원문 연결"로만. **'안전 갭 탐지' 표현 금지** — "교육자료가 안전·보건 지표를 한국 대비로 짚어준다"로.
- 코워커 외부평가 = **전송 → 코워커 구글 로그인 → 수신함에서 5영역 평가 → 역량대장 반영** (링크 아님). 시연 계정(가상 인물 응웬 티 란).
- 만족도(자아실현·업무애로 5문항)와 WHO-5 웰빙(개인 심리)은 **다른 축**임을 분명히.
- 데모 데이터는 **전원 베트남(VNM)** 통일 — 볼리비아 언급은 '인터뷰 출처'로만.
- 영상 순서 = 교육자료 생성 → 자료 번역 → 회의록 전송·공유 → 퀴즈 배포 → 코워커 평가 (실제 영상 구성과 일치).
