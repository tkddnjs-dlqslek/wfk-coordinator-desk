## 1. 실제로 쓸 수 있는 KOICA 데이터 (검증된 것만)

### ✅ 가장 확실한 즉시 사용 가능 자산 — "국가별 개발협력동향" 오픈API
- **data.go.kr ID 15075386**, 제공기관코드 **B260003** (= KOICA)
- 엔드포인트: `http://apis.data.go.kr/B260003/DevCprTrendService2/getDevCprTrendList2`
- **REST · JSON/XML · 무료 · 트래픽 100만 건** → 개인도 키 발급 즉시 사용
- **필드(검증됨)**: 동향ID, ISO국가코드, 국가명(한/영), 동향분류·분야 코드/명, 제목(한/영), **본문 5개 섹션(언어별)**, 출처, 관련링크, 작성자, 검수자, 작성일, 코로나 관련 지표
- **강점**: 한/영 이중언어 → 국내용·국제용 둘 다 가능. 본문 텍스트가 풍부 → **RAG/LLM 챗봇 재료로 최적**

### ✅ KOICA 포털 데이터 3대 분류
1. **주요 협력국별 데이터** 2. **사업 정보** 3. **개발협력 주요 지표**
- 추가로 oda.go.kr 시각화 포털에 **글로벌 개발지표(SDGs 데이터 + World Bank 지표)** — 경제·교육·보건·환경·거버넌스

> ⚠️ **주의 1**: oda.go.kr의 SDG/WB 지표는 제3자(WB/OECD/UN) 집계 데이터를 재제공하는 것 → 공모전이 요구하는 "data.go.kr 등록 KOICA 데이터"에 해당하는지 **자격 확인 필요**.
> ⚠️ **주의 2**: 봉사단 파견·연수생·무상원조 통계 데이터셋은 118건 안에 있을 것으로 추정되나 **개별 존재 미검증** → data.go.kr에서 "제공기관: 한국국제협력단(B260003)"으로 직접 검색해 확정할 것.

## 2. 심사위원이 가치를 두는 정책 프레이밍 (검증됨)

- ✅ **미션(그대로 인용 권장)**: "포용과 상생의 개발협력으로 인류 공영과 세계평화 증진에 기여"
- ✅ **#1 전략방향 = SDGs(지속가능발전목표) 달성 촉진** → 아이디어를 특정 SDG에 명시적으로 매핑하면 가점 가능성
- ✅ **제4차 국제개발협력 기본계획(2026~2030, 2026-02-26 발표)**: 비전 "혁신과 성과 기반 '보편적 가치'·'상생' 실현 K-ODA", **AI·문화를 중점분야로 신규 추가** → **AI/LLM 또는 문화 테마가 현재 정책과 정면 부합**
- ✅ **임팩트 앵커(기획서 도입부용)**: 1991~2024 KOICA가 174개국에 US$108억(약 10.8B) 무상원조
- 🟡 KOICA 디지털 전환 전략(2021~2025): 개도국 디지털 격차 해소 → "디지털 포용" 앵글 정당화 근거
